# 모아 — 팀의 과정을 모으다

팀 프로젝트의 작업, 참여자 역할, 근거 자료, 보완 의견을 기록하는 React 웹 앱입니다. 기여율은 활동 흐름 페이지에서 근거 기록과 함께 확인하는 보조 정보입니다.

## 실행

Node.js 20.19+ 또는 22.12+ 필요.

```sh
npm ci
npm run dev
```

개발 주소는 http://127.0.0.1:5173 입니다. `/api`는 Vite에서 로컬 백엔드 http://127.0.0.1:8080 으로 프록시합니다.

```sh
npm run build
```

배포 빌드 결과는 `dist/`입니다. 같은 상위 폴더의 Backend 저장소에서 `./dev/Start-Moa.ps1 -Build`는 이 결과를 Spring Boot 정적 리소스에 넣고 테스트 및 JAR 빌드를 수행합니다. 로컬 완성본은 프론트·API 모두 같은 주소 `http://127.0.0.1:8080`에서 동작합니다.

## 기능

- 회원가입, 로그인, 로그아웃, 토큰 만료 처리
- 팀 생성/참여/전환, 팀 소개 편집, 초대 코드 복사·재발급
- 팀장 위임, 탈퇴, 강퇴 및 권한에 따른 UI
- 기여 기록 CRUD, 7종 유형, 날짜, 규모, 참여자 역할·균등/직접 지분
- 제목/참여자 검색, 유형/상태/참여자 필터
- 링크 및 실제 파일 업로드·다운로드 (10MB 제한)
- 누락·수정 의견, 해결 내용 기록, 상태 전환
- 일/주/월 활동 흐름, 기여율과 개인별 근거 기록 조회
- 모바일 레이아웃, 키보드 사용 및 대화상자 포커스 관리

체험 팀은 백엔드의 `python scripts/seed_noclick.py`로 생성합니다. 노클릭 팀의 이름·역할과 회의 5회를 반영했으며 초기 날짜·세부 내용은 직접 수정할 초안입니다. 체험 화면의 변경도 실제 로컬 데이터베이스에 저장됩니다. 새 계정을 가입하면 별도의 팀을 만들 수 있습니다.
